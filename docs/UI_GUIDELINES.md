# UI Guidelines

## Design direction

- Minimal, focused UI
- Vertical, swipe-driven flow (short-form-feed feel)
- Fast transitions (Framer Motion)
- Card-based learning — one idea per screen

## Lesson UI

Each card shows:

- One idea only
- A swipe / tap interaction
- Immediate feedback on quizzes

## Home UI

- **Continue learning** — the primary action
- **Concept graph** — secondary
- **Recommended concepts**

## Visual style

- Clean, with light motion
- Diagram-forward — show ideas visually rather than describing them
- A developer-native aesthetic

## Avoid

- Long dashboards
- Deep or complex menus
- Dense walls of text
